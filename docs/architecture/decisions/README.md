# Architecture Decision Records

ADRs are numbered sequentially and become immutable after acceptance. A later ADR must explicitly supersede an earlier accepted ADR.

Required sections are: context, decision, alternatives, consequences, security/privacy, operations, migration, acceptance checks and review triggers.

The NorthStar Architecture Decision Register remains the governing checkpoint while these ADRs are Proposed. If a Proposed ADR differs from the register, the register wins unless a higher-authority source requires the difference.
