# Conversion Science-owned packages

This directory is reserved for purpose-specific reusable technical packages owned by Conversion Science and licensed for use within BIG, subject to the executed commercial agreement.

A package may be admitted only when it has:

- a clear reusable technical responsibility;
- a purpose-specific name;
- an explicit public API;
- tests and documentation; and
- its own ownership and licensing notice.

CS-owned packages must not contain BIG confidential data, personal data, BIG-specific business rules or BIG-specific authorization policy. Do not create a generic `@cs/shared` package. Directory placement documents intended organization but does not override the executed commercial agreement.
